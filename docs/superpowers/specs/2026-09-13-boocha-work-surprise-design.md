# Boocha 工作彩蛋与新版状态素材设计

## 目标

用用户提供的新版视频替换嗯嗯、工作、吃饭三个桌宠状态；在工作过程加入一个可选、低频且不打断专注计时的“送你”彩蛋。

## 素材与透明显示

- 用 `/Users/bytedance/Movies/嗯嗯.mov` 替换现有待机素材；用户界面中的“待机”统一显示为“嗯嗯”。
- 用 `/Users/bytedance/Movies/工作.mov` 和 `/Users/bytedance/Movies/吃饭.mov` 替换普通工作、吃饭素材。
- 用 `/Users/bytedance/Movies/送你.mov` 作为独立的彩蛋素材。
- 四段素材均复用 `KeyedVideo` 的逐帧 Canvas 扣图：采样边缘背景色，只移除从画布边缘连通的背景，保留角色内部的白色和其他本身颜色；最后保留现有底部羽化处理。

## 彩蛋状态和触发

- 增加仅内部可见的临时状态 `surprise`，界面名称为“送你”；它不出现在手动状态循环或原生菜单中。
- 用户手动进入普通工作时启动一个新的工作周期。若“开启彩蛋”关闭，或本周期未命中概率，正常保持工作状态。
- 开关开启时，每个新的手动工作周期独立以 30% 概率命中；命中后随机等待 5–30 分钟，再切换至“送你”。
- “送你”持续 1 分钟，显示气泡“小彩蛋送你”，结束后自动回到普通工作；期间不显示普通工作点击文案，也不被待机自动冒泡或饭点提醒打断。
- 倒计时和计时器只使用普通工作视觉，不会新建工作周期或触发彩蛋。饭点与其他自动行为同样不触发。
- 手动离开工作、关闭彩蛋或打开专注计时器时，清除尚未发生的彩蛋定时；不会在旧工作周期遗留触发。

## 设置

- 在设置页增加默认关闭、保存到本地的“开启彩蛋”开关。
- 开关下方显示说明：“进入工作状态时，彩蛋会随机出现。”
- 设置预览阶段也立即生效：关闭开关会取消当前等待中的彩蛋，重新开启只从下一次手动进入工作开始计算。

## 实现边界

- 扩展状态机事件，保持彩蛋生命周期（开始、到期、取消）可单独测试。
- 新增彩蛋调度器，以工作周期标识和时间戳避免 React 定时器在状态变更后误触发。
- 设置数据的归一化为旧本地配置补全 `surprise.enabled: false`，不改动用户既有气泡、饭点和计时器设置。
- 原生菜单仍只展示嗯嗯、工作、吃饭三个基础状态；若用户在“送你”期间通过菜单操作，立即取消彩蛋并采用所选基础状态。

## 验证

- 设置归一化测试覆盖默认关闭和旧配置迁移。
- 彩蛋调度器测试覆盖 30% 抽样、5–30 分钟等待、取消和一分钟结束。
- 状态机测试覆盖“送你”显示固定气泡、结束回工作与手动离开取消。
- 精灵测试覆盖四段视频的状态映射；扣图测试沿用并确认角色内部颜色不会被抠掉。
- 浏览器预览验证开关文案、新版状态素材、计时器不触发彩蛋，以及送你出现后自动恢复工作。
