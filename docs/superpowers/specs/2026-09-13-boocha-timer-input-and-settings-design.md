# Boocha 自定义倒计时与设置面板设计

## 目标

把自定义倒计时从设置页移到 Boocha 头顶的时间胶囊，并让设置页的关闭与气泡文案更像轻量 macOS 控制面板。

## 交互

- 右键菜单中，自定义倒计时的圆形按钮显示为 `....`。
- 点击后，Boocha 头顶显示加大的毛玻璃时间胶囊，初始为 `00:00`。
- 时间由四个数字组成：依次输入分钟十位、分钟个位、秒钟十位、秒钟个位；点击分钟或秒钟区域可把输入位置切到对应的两位。
- 必须填满四位、秒钟不超过 59、整体大于 00:00 后，播放按钮才能开始倒计时。开始后沿用暂停／继续与取消。
- 5／15／30 分钟预设行为不变。

## 设置面板

- 移除“自定义倒计时分钟数”，仅保留“倒计时结束提示”。
- 所有气泡文案（含倒计时结束提示）均显示为圆角底色标签；输入框加加号新增一条，标签上的 x 删除一条。允许删空；删空代表该类事件不显示气泡。
- 原有右上“关闭”文字按钮替换为左上角固定可见的 macOS 红色圆点关闭按钮。

## 视觉与边界

- 运行中与编辑中的时间胶囊都加大，维持毛玻璃、纯透明主窗口与桌宠不被按钮遮挡的既有边界。
- 新的自定义时长按秒启动，预设仍由分钟启动；总时长上限为 `99:59`。
- 不新增状态、不改饭点、互动或原生窗口振动逻辑。
