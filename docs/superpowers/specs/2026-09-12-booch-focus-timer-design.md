# Booch 桌宠：计时器 / 倒计时与右键快捷按钮设计

日期：2026-09-12

## 目标

把 Booch 从“会提醒吃饭的桌宠”升级成“陪用户工作的小桌宠”。新增计时器和倒计时功能：启动后桌宠切到工作视觉状态，头顶显示毛玻璃时间牌；运行期间不弹普通气泡，不被饭点打断。倒计时结束后切回待机，并显示一条用户可自定义的结束提示。

## 范围

本次只做本机功能，不做对象端同步、系统通知、声音提醒、历史统计或番茄钟报告。

## 交互入口

右键点击桌宠时，不再直接打开设置面板，而是在桌宠旁边显示三个圆形毛玻璃按钮，半包围桌宠：

- 倒计时：图标 `⏳`
- 计时器：图标 `⏱`
- 设置：图标 `⚙`

按钮大小适中、可点击、浮在透明窗口内。再次右键或点击某个按钮后，快捷按钮收起。

倒计时按钮点击后，三个快捷按钮临时切换为倒计时选项：

- `5`
- `15`
- `30`
- `自定义`

`5 / 15 / 30` 立即启动对应分钟数的倒计时。`自定义` 使用设置面板中的“自定义倒计时分钟数”作为启动时长；若用户还没有设置，默认 25 分钟。

计时器按钮点击后，立刻启动正向计时。

设置按钮点击后，打开设置面板。

保留：

- 单击桌宠：根据当前状态显示一句普通气泡。
- 双击桌宠：待机 → 工作 → 吃饭 → 待机循环切换。
- 菜单栏：切状态 / 打开设置 / 暂停提醒 / 恢复提醒 / 退出。菜单栏暂时保持现状，不在本次删除暂停项。

## 计时显示

启动计时器或倒计时后，桌宠头顶显示一个毛玻璃时间牌。它复用当前气泡的视觉语言，但内容是时间，不是普通文案。

- 计时器：从 `00:00` 正向递增。
- 倒计时：从选择的分钟数递减到 `00:00`。
- 时间牌显示在桌宠头顶。
- 运行期间不显示普通点击气泡、待机随机气泡或饭点气泡。

## 状态规则

新增一个独立的 focus timer 状态，不把计时逻辑塞进现有 `PetState`。视觉状态由渲染层根据 focus timer 决定：

- 计时器 / 倒计时运行中：视觉强制为 `work`，播放 `booch-work.mov`。
- 倒计时结束：停止 focus timer，视觉切到 `idle`，播放 `booch-idle.mov`，显示倒计时结束提示气泡。
- 正向计时器不会自动结束；后续版本可以补停止按钮。本次 V1 用再次点击计时器按钮来停止并回到待机。

普通状态机调整：

- 工作状态不再自动回待机，只能由用户自己切换。
- 吃饭状态结束后回到吃饭前的上一个状态，不再固定回待机。
- 饭点提醒只有在 focus timer 没有运行时才触发。
- 待机随机冒泡保留，但 focus timer 运行期间不触发。

## 设置面板

保留：

- 桌宠大小。
- 吃饭状态显示秒数。
- 待机随机冒泡间隔。
- 午饭 / 晚饭时间。
- 全部气泡文案。

删除：

- 暂停提醒。
- 专注时段不打扰。
- 工作状态显示分钟数，因为工作状态不再自动结束。

新增：

- 自定义倒计时分钟数，默认 25，允许 1–180。
- 倒计时结束提示文案，默认 `时间到，休息一下`。

现有 settings 存储继续使用 `localStorage`，保持本次改动小而稳。

## 桌面窗口行为

桌宠窗口继续保持：

- 透明窗口。
- 始终置顶。
- 可拖动。
- 记住位置。

设置面板打开时，桌宠仍然显示，不再隐藏。设置面板在桌宠旁边展开；用户调整桌宠大小时，桌宠实时变化，便于观察效果。

窗口尺寸需要从“只有桌宠”扩大为“桌宠 + 右侧设置面板 / 快捷按钮可见”的安全区域。关闭设置面板后恢复桌宠窗口尺寸和位置。

## 组件边界

- `focusTimer`：新增纯逻辑模块，负责计时器 / 倒计时状态、格式化时间、结束事件。
- `QuickActions`：新增右键快捷按钮 UI。
- `TimerBadge`：新增毛玻璃时间牌 UI。
- `SettingsPanel`：删掉暂停/专注字段，新增自定义倒计时与结束文案。
- `App`：协调 focus timer、状态机、饭点、随机冒泡、窗口尺寸。
- `nativeWindowClient`：支持“桌宠 + 设置面板”的窗口尺寸，不让设置面板遮掉桌宠。

## 测试策略

新增或更新单元测试：

- 倒计时格式化：`25:00`、`00:05`、`00:00`。
- 倒计时结束时产生结束事件。
- 计时器正向递增。
- focus timer 运行时饭点提醒不触发。
- 工作状态不再自动回待机。
- 吃饭结束回到上一个状态。
- settings 规范化包含自定义倒计时分钟数和结束文案。

手动验证：

- 右键出现半包围三个圆形按钮。
- 点倒计时后出现 `5 / 15 / 30 / 自定义`。
- 倒计时和计时器运行时，头顶显示时间牌，桌宠为工作状态，不冒普通气泡。
- 倒计时结束后切待机并显示结束文案。
- 设置面板打开时桌宠仍显示，调大小可实时看见变化。
