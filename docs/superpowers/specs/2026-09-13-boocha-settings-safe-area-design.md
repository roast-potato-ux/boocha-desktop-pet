# Boocha 设置面板顶部安全区设计

## 问题

设置面板自身目前承担滚动职责。红色关闭点使用 `position: sticky` 固定后，标题和设置内容仍在同一个滚动层内，因此滚动时会从红点下方经过并被遮挡。

## 方案

将设置面板拆为两个垂直区域：

- `settings-panel__safe-area` 固定在面板顶部，不参与滚动；其中包含 macOS 风格红色关闭点和“Boocha Desktop Pet / 设置”标题。
- `settings-panel__scroll` 占用其余可用高度并独立 `overflow-y: auto`；其中包含所有设置分组和保存按钮。

根面板不再滚动。安全区保持毛玻璃背景并用底部边界与内容区分隔，使滚动内容不会从关闭点或标题下方穿过。

## 验证

- 设置面板结构测试断言安全区与滚动区均存在，关闭按钮位于安全区。
- 浏览器预览中滚动到任意位置时，顶部红点和标题保持固定，首个设置分组从安全区下方开始。
- 运行完整前端测试和生产构建，确认设置编辑、实时预览与保存不受影响。
